# ОДУ второго порядка

## Постановка

Решить линейное дифференциальное уравнение второго порядка
$y'' + p\,y' + q\,y = f(x)$ с постоянными коэффициентами и, где заданы начальные
условия, — задачу Коши.

Конкретное уравнение пользователь не назвал (вопрос пропущен), поэтому:
- выведена общая формула решения (произвольные $p$, $q$, $f$);
- разобран пример $y''+3y'+2y=e^{x}$, $y(0)=1$, $y'(0)=0$.

Если появится своё уравнение — подставить коэффициенты и пересчитать.

## Файлы

- `_data/` — входных данных нет.
- `_work/` — временные файлы (пока не нужны).
- `_plots/` — `solution.png` (решение и асимптотика $e^x/6$), `family.png`
  (семейство при $y(0)=1$ и $y'(0)=0,1,2,3$).
- `report.md` — итоговый отчёт (docx/pdf собираются рядом).

## Ход работы

1. `DSolve` для однородного уравнения: $y_h = C_1 e^{r_1 x} + C_2 e^{r_2 x}$,
   $r_{1,2} = (-p \mp \sqrt{p^2-4q})/2$; для $p^2 = 4q$ — $(C_1+C_2 x)e^{rx}$.
2. `DSolve` для неоднородного с символьной $f$: частное решение выражено через
   интегралы вариации постоянных; формула приведена в `report.md`.
3. `DSolveValue` для примера: $y = e^x/6 + \frac{3}{2}e^{-x} - \frac{2}{3}e^{-2x}$.
4. Проверки:
   - общая формула подставлена в уравнение после `Activate` → остаток 0;
   - `wolfram_verify action=ode`: невязка на $[-1,4]$ ≤ $7.1\cdot10^{-15}$;
   - $y(0)=1$, $y'(0)=0$ — точно; $\max_{[0,3]} y \approx 3.4206$ при $x=3$.
5. Рисунки — `wolfram_render` в `_plots/`, просмотрены через `read_image`.

## Решения и допущения

- Постоянные коэффициенты, $f$ непрерывна.
- Случай $p^2=4q$ и кусочно-заданная $f$ — описаны словами, отдельно не считались.
- Нотация: $C_1, C_2$ — произвольные постоянные, $y_p$ — частное решение.

## Результаты

$$y(x) = \frac{e^{x}}{6} + \frac{3}{2}e^{-x} - \frac{2}{3}e^{-2x}$$
для задачи Коши $y''+3y'+2y=e^x$, $y(0)=1$, $y'(0)=0$. Отчёт — `report.md`.
