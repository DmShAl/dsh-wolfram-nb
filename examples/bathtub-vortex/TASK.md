# TASK: воронка в раковине (слив вращающейся жидкости)

## Постановка

Вопрос пользователя (14.11.2026): можно ли математически описать, как вода уходит
в слив раковины и почему образуется воронка, — или задача слишком сложная.

Ответ: полная задача (3D нестационарные Навье–Стокса + свободная поверхность + воздух)
действительно за пределами формулы, но наблюдаемые величины ловятся иерархией из
четырёх аналитических моделей. Нужно было: вывести их, посчитать числа для реальной
раковины и собрать отчёт.

## Модельная геометрия

| Параметр | Значение |
|---|---|
| радиус слива $a$ | 1 см ($A_d = 3.14\cdot10^{-4}$ м²) |
| площадь зеркала $A$ | 0.1 м² |
| начальная глубина $H$ | 10 см |
| $\rho,\ \nu,\ \sigma$ | 1000 кг/м³, $10^{-6}$ м²/с, 0.072 Н/м |

## Ход работы

1. **Торричелли**: $v=\sqrt{2gh}$, $Q=A_d\sqrt{2gh}$ → $t=(A/A_d)\sqrt{2H/g}$.
   Числа: $Q=0.44$ л/с, $t=45.4$ с (с $C_d=0.62$ — 73.3 с).
2. **Воронка**: $\Gamma=2\pi r v_\theta=\mathrm{const}$, радиальное равновесие
   $dh/dr=v_\theta^2/(gr)$ → $h=H-\Gamma^2/(8\pi^2gr^2)$; ядро
   $r_c=\Gamma/(2\pi\sqrt{2gH})$. Проверено `FullSimplify` (остаток $4\cdot10^{-19}$).
3. **Со стоком**: $v_r=-Q/(2\pi rh)$, Бернулли → кубика по $h$; горло при
   $\mathrm{Fr}=1$. При $\Gamma=0$ аналитика даёт $h=2H/3$, $r=1.30$ мм — совпало с `NSolve`.
   При $\Gamma=0.05$: $h=2.18$ см, $r=6.93$ мм.
4. **Вязкость**: вихрь Бюргерса — точное решение НС, остаток ровно 0; ядро 1.41 мм.
5. **Оценки**: $Re=8\cdot10^3$, $Ro=1.4\cdot10^5$, экмановское время 3.25 ч,
   $Bo=13.6$ (1 см) и 0.14 (1 мм).
6. Рисунки: `funnel-profiles.png`, `funnel-throat.png`, `funnel-3d.png` (`_plots/`).
7. Отчёт `report.md` → `report.docx` + `report.pdf` (PDFConv).

- $\Gamma$ — свободный параметр, из геометрии не выводится.
