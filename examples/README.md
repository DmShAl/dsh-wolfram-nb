# Примеры задач

Готовые расчётные задачи из рабочего каталога — как образцы структуры и отчёта.
Каждая сделана инструментами плагина и собрана `dsh-pdfconv`.

| Каталог | Что внутри |
|---|---|
| `bathtub-vortex/` | воронка в раковине: 4 модели (Торричелли, момент импульса, мелкая вода со стоком, вихрь Бюргерса), 3 рисунка, отчёт MD/DOCX/PDF |
| `ode-second-order/` | линейное ОДУ 2-го порядка: общая формула с параметрами, пример, 2 рисунка, отчёт MD/DOCX/PDF |
| `lorenz-example/` | аттрактор Лоренца: LaTeX-отчёт и 4 рисунка |

Структура образца: `TASK.md` (постановка и память), `report.md` (или `report.tex`),
`report.docx`/`report.pdf` (сборка), `_plots/` (финальные рисунки).

`_work/` в примерах нет намеренно: это временные файлы, они не нужны для воспроизведения.

Чтобы начать свою задачу, скопируй `../workspace/` в отдельный каталог и работай там
(`node tools/new-task.mjs <имя>` создаст каркас).
